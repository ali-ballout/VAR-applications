What is inside

  • viral_functional_annotations.tsv.gz — 4,572,619 GO annotations, one per row, 22 provenance columns
  • protein_to_study_virus_mapping.tsv.gz — 370,585 UniProtKB proteins with mapping status and justification
  • annotation_coverage_by_virus.tsv — all 3,288 study viruses, one row each
  • coverage_summary.tsv, coverage_by_aspect_and_evidence.tsv — per-cohort breakdowns
  • unmatched_identifiers.tsv — 1,755 viruses with no annotation, plus 2 unmappable source taxids
  • unmapped_annotation_records.tsv.gz — 684 rows held out of the main table
  • ambiguous_mappings.tsv — empty by result: no strain descends from more than one study species
  • viralzone_family_traits.tsv — family-level only, host-leakage sections withheld
  • go_terms_used.tsv — 927 GO terms labelled from release 2026-07-26
  • download_manifest.json — every source, version, version evidence, licence, SHA-256 of all files
  • acquisition_log.txt — what was attempted, used, and blocked
  • raw/ — 1,808 actual retrieved source files plus saved version evidence
  • scripts/ — stdlib-only reproduction scripts with RUN_ORDER.txt

Coverage is strongly non-random across cohorts. The benchmark and test subsets are far better annotated than the full set. Any evaluation built on these annotations inherits that bias — it is a property of the sources, not of the extraction.
Only 244 of 3,288 viruses carry annotations on their own species TaxID. For 1,289 more, the available evidence sits on strain or isolate descendants, supplied as VERIFIED_DESCENDANT with original taxid and accession intact. Whether to treat those as species-level evidence is left open.

Temporal eligibility

GO annotations come from the QuickGO annotation snapshot timestamped 2026-07-28 10:08 UTC — UniProt-GOA release 236, before the 2026-08-18 cutoff. That is a dated snapshot, not an inference from each annotation’s own date field, and it is corroborated by the GOA FTP archive headers for goa_uniprot_all.gaf.236.gz (Last-Modified 29 Jul 2026), saved under raw/provenance/. Highest annotation date observed: 2026-07-27. Rows dated after the cutoff: zero.

UniProtKB protein records are release 2026_04 (2026-11-04), after the cutoff. They are used only for protein and organism identity, never as annotation evidence, and are flagged ineligible in the manifest. ViralZone publishes no dated release, so all of its rows carry temporally_eligible=false.

Constraints observed

  • No virus–host association labels were used at any stage.
  • No model was trained; no virus–virus similarity was computed.
  • Family-level text was never promoted to species annotations.
  • Strain annotations keep their original identifiers and are never relabelled as species-level.
  • Missing annotation is recorded as missing, never as a biological negative.
  • 206 ViralZone sections matching host / receptor / tropism / transmission / vector / reservoir / pathology / epidemiology patterns were withheld to prevent label leakage.
  • The 11.7 GB goa_uniprot_all.gaf.236.gz was not downloaded: QuickGO serves the same release filtered by TaxID server-side. EBI publishes no checksums for archived GOA releases, and the manifest says so rather than implying verification.
